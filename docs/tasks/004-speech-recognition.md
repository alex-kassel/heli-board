# Task 004 — Speech recognition

Prerequisite: Task 003 complete.

Select recognition adapter based on measured Android compatibility and multilingual requirements. Implement explicit microphone permission, start/stop/cancel, lifecycle cleanup, error handling, and transcript preview. Never auto-send or log user speech. Document limitations of mixed-language recognition and network/offline behavior.

Acceptance: tested on device/emulator where possible, no recording after cancellation, errors recover gracefully, no sensitive-field recording.
